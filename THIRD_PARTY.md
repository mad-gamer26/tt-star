This project requires the TeamTalk 5 SDK, which is owned and licensed
separately by BearWare.dk. It is not included in this repository and is not
covered by this project's Apache-2.0 license.

When the SDK is missing, the bot can discover and download the current
Standard SDK archive directly from BearWare's official download page. Before
downloading, it displays BearWare's trial and licensing notice and asks the
user for confirmation.
